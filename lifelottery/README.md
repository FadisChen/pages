# 人生籤 Life Lottery

一個純靜態的瀏覽器遊戲：你不能選擇出生在哪個國家、是男是女、家裡有沒有錢。系統依各國真實統計替你抽一支「人生籤」，
然後你一年一年地走完這輩子，在重要關頭做選擇，最後依統計發生的方式離開，看一份屬於這個人的人生回顧。

> 概念靈感來自《80 億分之 1》（[1in8b.life](https://1in8b.life)）——「依真實統計隨機出生、走完一生」。
> 人生籤的名稱、文案、介面、程式與事件內容皆為獨立設計，沒有複製原作。

沒有建置步驟、沒有後端、沒有帳號、不需要任何 API key。放在任何靜態伺服器（例如 GitHub Pages）就能玩，也可以離線玩（PWA）。

## 怎麼玩

1. **首頁**：看見世界此刻約有多少人、每秒出生多少嬰兒。按「開始投胎」。
2. **設定**：選出生年代（過去 1955–1990／現在／未來 2040–2070／隨機）、抽籤方式（依新生兒人數／依現有人口）、人生長度
   （約 10／30／60 分鐘）、要不要自動抉擇。
3. **抽籤**：國名輪轉後停下，揭曉你的國家、城市或鄉村、性別、家庭經濟（五等分）與名字，並對照該國與世界平均。
4. **人生**：時間逐年流動，頂端是年齡與五項狀態（健康、幸福、知識、財富、人際）。遇到重大事件會暫停並出現選擇卡；
   可以暫停、1×／2×／4× 倍速、跳到下一年，或打開「自動抉擇」讓人生自己走。
5. **離世**：死亡時間與原因依統計發生，不是玩家選的結果。
6. **回顧**：壽命與本國／世界平均的對照、五項狀態的曲線、重要時刻、學歷／工作／伴侶／子女／住過的國家，
   可以留一句話給這個角色、下載分享圖卡，或收進「前世記錄」。
7. **前世記錄**：歷次人生都存在你的瀏覽器裡（`localStorage`），可以匯出／匯入 JSON。

資料只存在你自己的瀏覽器，不會上傳。

### 內容提醒

遊戲會出現疾病、死亡、暴力、貧窮、戰亂、歧視等「統計上真的會發生」的事，建議 15 歲以上遊玩。內容守則：

- 不在任何選項裡提供自傷或自殺的做法；死因為自殺時，回顧頁會附上求助資源（台灣 1925 安心專線、1995 生命線）。
- 不用刻板印象寫國家或族群；各國事件依該國的經濟、地區與年代條件觸發，而不是依標籤。
- 文案用繁體中文（臺灣用語）、第二人稱、具體而溫和，不說教。

## 方法與資料來源

資料與抽籤規則的細節寫在 `js/data/countries.js` 檔頭，這裡是摘要。

- **國家統計**：173 個人口 ≥ 50 萬的國家與地區（涵蓋全球 99.9% 以上人口，含台灣）。來源皆為開放資料：
  OWID（含聯合國 WPP 衍生值）的人口、平均餘命、人均 GDP、極端貧窮、吸菸率；IHME 全球疾病負擔 2017 的嬰兒死亡率、
  自殺率；UN IGME 的五歲以下死亡率；Gapminder／UN WPP 的生育率與 1970 年資料；UNDP 的受教育年限；
  UN 的都市人口比例、初婚年齡；出生性別比來自 Chao 等人 2019。
- **估計值**：高等教育毛入學率、道路交通死亡率、童婚比例、他殺率在建置環境中找不到可下載的開放資料集，
  是依記憶填入的近似值，在每個國家的 `est` 欄位標示；其他欄位若使用推估也會列在 `est`。
- **年代**：過去（1955–1990）與未來（2040–2070）用 1970 與 2050 的資料順著趨勢外推，GDP 與人口幾何內插；
  所得分組依「當年」人均 GDP 判定（1975 年的南韓是中低所得國家）。
- **抽籤**：依新生兒人數（年出生數）或現有人口加權；性別依出生性別比；家庭經濟為五等分；城鄉依該國都市化率與家庭財富。
- **壽命**：每個國家（與年代、性別）有一張生命表，以二分法校準到該國預期壽命；個人風險乘數（健康、財富、吸菸、疾病、
  事件）再以 `js/data/riskref.js` 正規化，使平均死亡年齡貼近統計，而個別人生有長有短。死因依年齡與國家的死因結構抽出。
- **事件**：約 570 則事件（成長、青年、工作、家庭、移居、健康、老年、世界大事、地區事件）加上 170 多句「平凡的一年」，
  依年齡、年代、國家、所得、城鄉、家庭、職業與先前的選擇觸發。事件之間的前後關係用旗標與「後續事件」串起來。
- **敘事一致性**：文字不能和狀態矛盾（孩子不會在辦公室過夜、沒有伴侶就不會提到另一半、2000 年以前沒有智慧型手機）。
  有一支自動稽核器（`tests/lib/coherence.mjs`）模擬數千段人生、檢查每一句文字；詳見下方測試說明與 `PLAN.md` 的 Phase 3B notes。

## 執行與測試

不需要安裝任何套件（只需要 Node 22）。

```sh
cd lifelottery
npm test                  # 全部單元與模擬測試（node --test tests/*.test.mjs），約 2.5 分鐘
node --test tests/coherence.test.mjs   # 只跑敘事一致性稽核（約 20 秒）
node tests/e2e.mjs        # 端對端測試（Playwright + Chromium，需要已安裝 Chromium；會自己啟動靜態伺服器）
```

本機玩：在 `lifelottery/` 底下開任一靜態伺服器，例如 `npx http-server .` 或 `python3 -m http.server`，
用瀏覽器開啟網址即可（直接雙擊 `index.html` 不行，ES modules 需要 http）。

### 工具

```sh
node tools/coherence-scan.mjs 2500 myprefix        # 模擬 N 段人生並列出文字與狀態的矛盾（--rule=a,b、--samples=n、--json=檔案）
node tools/read-life.mjs --seed x --era past --country TWN --gender F   # 把一段人生印成可讀的日誌（--urban --wealth --birthYear --draw）
```

### 重新產生資料與校準

```sh
npm run build:data                  # 下載原始 CSV 並重建 js/data/countries.js（tools/fetch-raw.mjs + tools/build-data.mjs）
node tools/calibrate-risk.mjs 30000 4   # 重新校準個人風險乘數，產生 js/data/riskref.js（約 10 分鐘）
```

只要改動了會影響風險的內容（事件的 `addRisk`／健康相關效果、疾病、系統規則、壽命相關的條件），就要重跑校準，
再跑 `npm test` 確認平均壽命仍貼近各國統計。

## 資料夾結構

```
index.html · manifest.webmanifest · sw.js · icon.svg · icons/   靜態頁、PWA（sw.js 預先快取整個遊戲；檔案清單變動時要升 CACHE_VERSION）
css/style.css                                                  樣式（色彩全用 CSS 變數，淺色／深色）
js/main.js · storage.js · strings.js · theme-init.js           進入點、localStorage、所有介面字串
js/ui/                                                         畫面（screens/）、圖表、分享圖卡、節奏控制
js/engine/                                                     純邏輯，不碰 DOM，可在 Node 執行（見 js/engine/README.md）
js/data/                                                       countries（產生）、eras、names、causes、conditions、yearly、riskref（產生）
js/data/events/                                                事件：seed、childhood、youth、adult_work、adult_family、migration、health、aging、world、regional
tools/                                                         資料建置、風險校準、稽核與讀檔工具（tools/raw/ 為下載的原始資料，不進版控）
tests/                                                         單元、模擬、一致性稽核、PWA、e2e 測試
PLAN.md                                                        開發規劃與各階段筆記
```

遊戲程式（`lifelottery/` 之內）完全獨立：沒有指向外部的 import 或 fetch，localStorage 鍵為 `lifelottery.*`，
e2e 測試包含檢查這一點的隔離掃描。
