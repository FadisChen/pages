01ABOUT / 關於

我的工作，始於一個問題。What if we try?

一項技術真正有趣的時刻，是它開始解決人的問題。這也是我持續往返於產品體驗、前後端工程與 AI 應用之間的原因。

我關心的不只是功能能否實現，還包括架構是否清晰、互動是否自然、工具是否真正幫上忙。比起單一技術標籤，我更喜歡從問題出發，跨越邊界把事情完成。

04HOW I WORK / 做事方式

THINK → BUILD → VALIDATE

02 / BUILD
