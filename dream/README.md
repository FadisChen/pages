# 星願手札 · Starwish Journal

以《美少女夢工廠2》的長期養成結構為參考的**原創網頁遊戲互動樣板**。陪伴莉亞從10歲到18歲，安排三旬生活，管理課程、工作、壓力與健康，探索四區、參加年度競賽，並迎向32條職涯與多維人生後日談。

## 啟動

在儲存庫根目錄執行：

```sh
python -m http.server 8000
```

瀏覽 `http://localhost:8000/dream/`。必須使用HTTP伺服器，不能直接用`file://`載入ES Modules。無建置與安裝步驟，可由GitHub Pages的根目錄靜態服務直接載入`/pages/dream/`。

## 如何遊玩

1. 在「育成行程」安排上、中、下旬的課程、工作或休息。
2. 查看預付費用；生活費每月40G，打工收入按能力／壓力／熟練結算。
3. 按「開始這個月」，選擇事件後結算。可在手札查看逐旬結果。
4. 十二歲起開啟魔法、餐館與外出修行；每年十月參加選定的收穫祭。
5. 在「成長換裝」購買、取得或切換20套衣服（含泳裝、禮服、惡魔裝、女僕服等）。立繪依年齡自動變為四階段。
6. 在「未來圖鑑」查看職涯條件。十八歲取得職涯＋親情／友誼／身心／財務後日談。

## 可選 Gemini BYOK

設定中選擇Gemini模式，輸入API key與帳號可用的model name（預設`gemini-3.5-flash-lite`，不保證各帳號都能使用）。模型需支援`generateContent`與JSON結構化輸出。

預設金鑰只放在記憶體；勾選後可用sessionStorage在此分頁保留。按「清除金鑰」可立即移除。瀏覽器工作階段還原可能延長保留時間。金鑰不寫入進度、匯出檔、GitHub或URL。請求由瀏覽器直接送Google，可能計費；測試按鈕同樣會送一次生成請求。

AI改寫本地選出的合法情境，不能自行改數值／結局／成就。無金鑰可使用18種內建情境；AI失敗時可選用本地版本繼續。未進行真實金鑰的端到端測試。

## 存檔

進度在此瀏覽器自動存檔，可匯出JSON備份；設定內可匯入。匯入和新遊戲都要求確認取代進度。損壞的既有資料不自動覆寫。

## 測試

```sh
node --test dream/tests/*.test.mjs
```

使用Node內建測試，無外部套件。詳見 [驗證記錄](VERIFICATION.md)。

## 目錄

- `js/game.js`：純規則、18事件、11活動、20服裝、32職涯與後日談。
- `js/gemini.js`：結構化請求／驗證／逾時與錯誤。
- `js/app.js`：UI、設定、路由、存檔與互動。
- `assets/`：背景、4階段×20服裝透明圖集、SVG徽章。
- `tests/`：規則、存檔、Gemini模擬測試。

目前是樣板，尚未包含完整戰鬥、自由對話、結局CG、語音、雲端存檔或後端。所有變更限定在`dream/`。
