## 1. 產品結論

製作一款能在 GitHub Pages 運作、無須帳號的單人養成遊戲。玩家以監護人身分陪伴女兒莉亞由 **10 歲成長至 18 歲**，在 **96 個月、288 旬**的有限時間裡，平衡教育、工作、生活費、身心狀態與探索，讓長期選擇累積為不同人生。

遊戲價值來自「看見她長大」和「培育取捨產生可理解的結果」。**Gemini 是可選的創作能力**：沒有金鑰仍可完整推進到結局；有金鑰可讓符合遊戲情境的事件產生更多敘事變化。金鑰與 model name 由玩家自行提供，不綁定特定模型或服務方案。

### 成功體驗

1. 第一分鐘就能理解女兒狀態、金錢與三旬行程。
2. 第一次月結算能看懂「安排 → 事件 → 選擇 → 成長與收支」。
3. 第一場收穫祭成為中期目標，獎項可以支撐高階職涯。
4. 年齡、立繪、服裝、課程解鎖與事件語氣讓八年成長可被感知。
5. 結局同時呈現職涯與生活，並解釋哪些選擇導向此結果。

## 3. 目標玩家與核心循環

- 喜歡單機養成、資源規劃、多結局與角色陪伴的玩家。
- 每次遊玩5–15分鐘；可一次推進數個月，也可停留規劃。
- 平台：桌機優先，手機直向可用；繁體中文，鍵盤可操作。

**每月循環**：查看狀態／圖鑑 → 選衣服與目標 → 排三旬／探索地點／競賽方向 → 檢查預算 → 選出事件情境 → 內建敘事或Gemini改寫 → 玩家選擇 → 逐旬結算 → 事件數值與旗標 → 十月競賽／生日津貼 → 存檔與手札 → 下個月。

在玩家選擇事件以前不扣金幣、不增長月份。待處理事件會存檔；重新整理後可以繼續，不重複呼叫AI。

### 4.2 能力與評價

能力：體力、智力、藝術、禮儀、道德、武術、魔法、料理。狀態：健康、壓力、親情。全部0–100。

四種評價：戰士、魔法、社交、家事，與能力分開記錄。**能力表示能做什麼；評價表示累積的訓練與社會認可**。四評價映射是本案簡化，詳細職業／聲望計算留待平衡版本。

- 壓力≥70：非狀態正向能力收益減半向下取整；對應評價改為+1。
- 壓力≥80：打工收入降為45%；該旬結束若仍≥80，健康-12。
- 健康<30：非休息行程自動改為在家休息，不扣該活動費、不累積原活動經驗。
- 無死亡／不可逆失敗。健康、關係不佳會反映於後日談。

### 4.5 事件系統

**樣板實裝18個事件情境**，每次有3個選項。依條件選出情境後，可用內建文本或AI改寫。條件／旗標由遊戲保存，Gemini不能自行新增成就。

| 類型 | 樣板事件／條件 | 正式版擴充方向 |
| --- | --- | --- |
| 初遇／家庭 | 第一次相遇、生日、家庭日常、壓力過高、健康不佳 | 教養方針、衝突修復、自主選擇 |
| 季節／節慶 | 夏日急雨、冬日壁爐、收穫祭前奏 | 生日禮物、新年、豐收、暴風雨 |
| 課程／專長 | 老師推薦信→晨光畫作、禮儀茶會 | 課程晉級、失敗、師生關係、流派選擇 |
| 工作 | 農場帶領學徒、第一份餐點 | 升遷、顧客、同行競爭、開店 |
| 友情 | 米菈同桌事件→16歲後離別約定 | 多角色關係值、共同任務、信任分支 |
| 冒險／職涯 | 路途岔口、遺跡→星之鑰、山道→騎士推薦 | 森林精靈、城鎮委託、派系與道德抉擇 |

樣板規則：

1. 初遇、疾病、壓力、生日、專長與支線事件優先；依事件定義順序處理。
2. 已達成的單次旗標不重複授予。一般事件避開最近2個月同事件；沒有其他適用情境時可回到日常事件。
3. 事件在月初選取，參照已完成的過往經驗；同月修行成果於下月起觸發支線。
4. 旗標在選擇後授予；樣板同一情境的三選項共用核心進度旗標，差別在能力／關係效果。
5. 三個選項使用已登錄的效果：研究、善意、創作、勇氣、陪伴。選項先顯示數值，玩家可預期結果。
6. 完整版需增加選項專屬旗標、失敗分支、互斥路線及冷卻權重，避免所有支線都可同時完成。

**正式MVP內容目標**：至少80個經人工審核的情境、12條多階段事件鏈、6名NPC、4類年度活動；此為後續範圍，非目前完成數。應先把事件定義移入版本化資料包，再加入製作工具及模擬檢查。

### 4.7 年度收穫祭

每年十月的月末結算參加藝術、舞會、料理、武術其中一項。本案改編為不另外消耗三旬的年度檢定，與原作完整比賽演出有區別。

- 成績 = 四捨五入（主能力×0.7＋對應評價×0.3－壓力×0.2）。
- 得獎門檻 = 32＋已過完整養成年數×5，隨年資提高。
- 得獎：200G、對應評價+8、獎牌及類別旗標。
- 未得獎：評價+2，沒有金幣獎勵。
- 正式版增加對手、預賽、過場演出、年度冠軍差異；不以AI任意判勝負。

精確門檻與先後順序以 `js/game.js` 的 `ENDINGS`／`ENDING_PRIORITY` 為唯一來源；UI直接讀取，避免PRD複製數字後與程式分歧。例如宮廷畫師要求藝術、繪畫經驗、社交評價、完成畫作及藝術祭獎項；不是只取最高能力。

正式版可再增加：事件鏈專屬結局、公開／隱藏職涯、成年後的同齡伴侶與自主關係選擇、多周目成就收藏。伴侶不作為女兒價值的唯一衡量，也不把未成年時期的陪伴改寫為戀愛。

## 6. Gemini BYOK 規劃

### 本版採用：受情境約束的事件編劇

遊戲先選出合法事件與效果；Gemini改寫標題、正文、選項及事後短敘事，提供更自然的情境細節。玩家輸入自己的API key與model name，預設`gemini-3.5-flash-lite`，支援`models/`前綴正規化。**它不是判定權威，沒有金鑰也不是殘缺模式。**

- 介面：內建／Gemini模式、密碼欄位、model name、分頁記住、清除、測試生成。
- REST：`POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`。
- 以`x-goog-api-key`標頭傳送，金鑰不放URL。
- `responseMimeType: application/json`、`responseJsonSchema`限制事件格式。
- 本地再驗證字數、3個選項、合法效果ID，以及與原情境選項順序一致。
- 輸出只作文字渲染，無HTML／腳本／工具執行能力。
- 不提供任意API endpoint欄位，避免金鑰被轉送至未知主機。

### 請求、隱私與費用

- 預設金鑰只存在記憶體；重新整理清除。
- 可明確勾選`sessionStorage`保留；瀏覽器工作階段還原可能延長保留，清除按鈕可立即移除。
- 遊戲進度與模式／模型設定可用localStorage保存；存檔匯出不包含金鑰。
- 傳送狀態、月齡、行程、核定事件、最近3次標題／選擇；不傳完整存檔、其他頁面資料或個資。
- 每次生成最長30秒、最多4096輸出tokens；不自動重試。
- 使用者重試或測試連線會額外產生請求。畫面提示可能計費，實際費用取決於帳號／模型。
- 400／401／403／404／429／伺服器／網路／逾時分別提供可理解訊息，不回顯上游錯誤全文或金鑰。
- 失敗時不扣遊戲費用、不推進；由玩家選擇重試或使用內建版本。

### 擴充能力，保持可替換

| 用途 | 優先級 | 需要先具備的限制 |
| --- | --- | --- |
| 角色日常對話 | P1 | NPC設定、有限記憶、單月對話次數與禁止直接變更狀態 |
| 事件草稿工作坊 | P1 | 產生資料包→預覽→人工核定；任意新效果需映射既有效果庫 |
| 成長回顧／結局信件 | P1 | 只引用確認過的歷史與既定職涯，無新成就 |
| 冒險旁白 | P2 | 明確提供戰鬥判定結果，再讓模型描述 |
| 自訂模型供應商 | P2 | `NarrativeProvider.generate(seed, context)`介面；固定允許來源與金鑰隔離 |

現在的模組分離已提供可替換邊界，但尚未提供完整供應商外掛系統。敘事自然度與內容適齡仍需人工抽樣評估；prompt與schema不是語意正確性的保證。

技術參考：[Google結構化輸出文件](https://ai.google.dev/gemini-api/docs/structured-output)、[generateContent 結構化輸出](https://ai.google.dev/gemini-api/docs/generate-content/structured-output)。相容性需以使用者所選模型與帳號實測。

## 7. 樣板UI與美術

### 視覺方向

羊皮紙暖白、鼠尾草綠、舊金細節，水彩繪本背景與日系原創人物。主畫面是生活場景，養成資訊保持可讀；不把所有功能擠成數字儀表板。手機改為上方導覽、場景與狀態縱向排列。

使用內建imagegen生成：王國背景1張、20套服裝×四年齡階段。服裝以4張5欄×4列圖集批次生成，再依使用者要求切分為80張獨立透明WebP；不在遊戲執行時即時生成衣服。每套服裝有固定ID、取得條件與規則效果。品牌星形徽章使用原生SVG。

生成記錄、提示詞與檔名見 [ASSETS.md](ASSETS.md)。不使用原作角色、標誌、截圖或音樂。未實作人物骨架動畫、表情切換、音效與完整戰鬥演出。

## 8. 技術、資料與可靠性

- 原生HTML／CSS／ES Modules，免建置，符合此儲存庫既有模式。
- `game.js`：純規則、活動、事件條件、服裝、評價、結局、存檔驗證。
- `gemini.js`：結構化生成、模型正規化、驗證、逾時／錯誤處理。

- 存檔有版本／範圍／活動／歷史／待處理情境驗證，匯入上限2MB。這是單機存檔格式驗證，不是防作弊系統。
- 未知／損壞存檔不靜默覆寫，保留原資料供匯出後再開始新遊戲。
- 網路失敗與不支援模型可回到本地事件；生成期間鎖定互動，避免重複推進。
- CSP限制腳本與連線來源；外部文字跳脫後顯示，不執行模型HTML。
- 無追蹤器、外部字型或第三方執行期套件。
